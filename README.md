# Менеджер паролей с шифрованием (PRJ2)

CLI-приложение на Python: хранение паролей в SQLite3 с шифрованием Fernet.

## Особенности

- Мастер-пароль: при первом запуске создаётся, хранится как хеш SHA-256 (сам пароль нигде не сохраняется)
- Пароли сайтов шифруются алгоритмом Fernet, ключ лежит в файле `.key`
- Генератор надёжных паролей (длина 8–64, выбор типов символов)
- Копирование пароля в буфер обмена (если установлен pyperclip)

## Установка

```bash
pip install cryptography      # обязательно
pip install pyperclip         # по желанию — для копирования в буфер
```

## Запуск

```bash
python3 password_manager.py     # на Windows: python password_manager.py
```

## Использование

### Первый запуск

При первом запуске программа попросит создать мастер-пароль:

```
Добро пожаловать! Это ваш первый запуск.
Создайте мастер-пароль для доступа к приложению.
Введите мастер-пароль:
Подтвердите мастер-пароль:
Мастер-пароль успешно создан!
```

### Работа с приложением

После успешной аутентификации вы увидите главное меню:

```
1. Добавить новый пароль
2. Получить пароль
3. Список всех паролей
4. Удалить пароль
5. Сгенерировать пароль
6. Выход
```

### Как копировать пароль

При получении пароля (пункт 2) или после генерации (пункт 5) программа
предложит скопировать пароль в буфер обмена. Для этого должна быть
установлена библиотека pyperclip:

```bash
pip install pyperclip
```

Если она не установлена — просто выделите пароль в терминале и скопируйте
вручную (Cmd+C на Mac, Ctrl+C на Windows).

## Файлы проекта

- `password_manager.py` — весь код: функции БД, функции шифрования, CLI-обработчик
- `passwords.db` — база данных (создаётся при первом запуске)
- `.key` — ключ шифрования (создаётся при первом запуске)
- `prompt.txt` — промпт из урока, по которому сгенерирован проект

## Важно

Не удаляйте и не теряйте файл `.key` — без него расшифровать сохранённые
пароли невозможно. Не публикуйте его (в git он попадать не должен).
