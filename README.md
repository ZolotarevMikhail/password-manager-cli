# Менеджер паролей с шифрованием (PRJ2)

Desktop-приложение на Python с окном-интерфейсом (tkinter): хранение паролей в SQLite3 с шифрованием Fernet.

## Особенности

- Мастер-пароль: при первом запуске создаётся, хранится как хеш SHA-256 (сам пароль нигде не сохраняется)
- Пароли сайтов шифруются алгоритмом Fernet, ключ лежит в файле `.key`
- Генератор надёжных паролей (длина 8–64, выбор типов символов)
- Копирование пароля в буфер обмена через сам Tkinter (pyperclip не нужен)

## Файлы проекта

- `gui.py` — окно приложения: вход, генерация, список, кнопки внизу
- `password_manager.py` — вся логика: база, шифрование, генератор (можно запустить и в терминале)
- `test_gui.py` — самопроверка интерфейса (запуск в отдельной временной папке, базу не трогает)
- `passwords.db` — база данных (создаётся при первом запуске)
- `.key` — ключ шифрования (создаётся при первом запуске)
- `prompt.txt` — промпт из урока, по которому сгенерирован проект

## Как запустить окно

```bash
cd PRJ2
python3 gui.py     # на Windows: python gui.py
```

Библиотека нужна одна: `pip install cryptography`.

При открытии окно спрашивает мастер-пароль (при первом запуске — предложит
создать; запишите его в надёжном месте, без него хранилище не откроется).
Дальше в одном окне: блок «Сгенерировать пароль» (длина и галочки типов
символов), форма «Добавить пароль в базу», поиск по названию и логину
(почте: набрали логин — Enter — пароль сразу в буфере обмена), таблица
сохранённых записей и линейка быстрых кнопок внизу:

```
Показать пароль | Копировать пароль | Удалить | Обновить список | Выход
```

## Значок для быстрого запуска (Mac)

- `Менеджер паролей.app` — приложение-запуск: двойной клик открывает окно, без терминала. Перетащите его в левую часть Dock — запуск одним кликом.
- Внутри `.app` — скрипт, который запускает `gui.py`; если у вас другой путь к Python, поменяйте его в `Contents/MacOS/запуск`.

## Терминальная версия

```bash
python3 password_manager.py
```

Там работает меню:

```
1. Добавить новый пароль
2. Получить пароль
3. Список всех паролей
4. Удалить пароль
5. Сгенерировать пароль
6. Выход
```

Копирование в буфер обмена в терминале — если установлена библиотека
pyperclip (`pip install pyperclip`); без неё пароль выделяется и копируется
вручную (Cmd+C на Mac, Ctrl+C на Windows).

## Важно

Не удаляйте и не теряйте файл `.key` — без него расшифровать сохранённые
пароли невозможно. Не публикуйте его (в git он попадать не должен).
